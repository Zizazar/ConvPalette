# План разработки — ConvPalette

Итеративный план: каждая фаза даёт работающий результат. MVP = фазы 0–4.

> **Статус на 2026-07-18:**
> - ✅ Фаза 0 — каркас Tauri + SvelteKit собран и запускается.
> - ✅ Фаза 1 — overlay-окно, трей, глобальный хоткей (настраиваемый, отказоустойчивые запасные комбинации), перетаскивание окна и drag&drop файлов.
> - ✅ Фаза 2 — single-instance-агрегация и передача путей; регистрация контекстного меню из приложения (`integration.rs`, тумблер в настройках) + PS-скрипты как запасной путь. Win11 модерн-меню — в Фазе 5.
> - ✅ Фаза 3 — движок пресетов + рекомендации + выполнение ffmpeg с прогрессом; авто-загрузка ffmpeg (BtbN); отмена задач; папка вывода и шаблон имени из настроек; очередь с лимитом параллелизма (2 процесса ffmpeg одновременно).
> - ✅ Фаза 4 — ИИ через OpenRouter + Ollama; ИИ отдаёт «опции» ffmpeg (безопасно, пути строит приложение) + валидатор; API-ключ в Credential Manager (`keyring`); метаданные через ffprobe с кэшем (путь+mtime); запросы асинхронные (`spawn_blocking`, UI не блокируется); авто-ретрай — ошибка ffmpeg уходит обратно ИИ на исправление (до 2 фиксов, перезапуск только упавших файлов). Осталось: реальный прогон с ключом пользователя.
> - ✅ Фаза 6 — полный экран настроек (провайдер/модель/ключ, папка вывода, шаблон имени, хоткей захватом нажатия, тема, язык, автозапуск, контекстное меню, скрытие по фокусу — опционально); история запросов (`history.json`, 30 записей); тёмная/светлая/системная тема; локализация ru/en; анимация появления палитры; иконки Material Symbols (Google Fonts, инлайн-SVG).
> - ✅ Панель файлов — карточки слева от палитры: миниатюра (кадр видео / волна аудио / превью изображения), имя, размер, разрешение, длительность; папки — со сводкой по содержимому. Клик открывает модалку предпросмотра (изображение / видео / аудио с плеером), папка — Проводник. Миниатюры кэшируются в `%APPDATA%\ConvPalette\thumbs` (`cards.rs`).
> - ✅ Фаза 7 — NSIS-инсталлятор (per-user, ru/en, `npm run tauri build`); хуки деинсталляции чистят реестр (`src-tauri/windows/hooks.nsh`); руководство пользователя `docs/USER_GUIDE.md`. Отложено: подпись кода (нужен сертификат) и авто-обновления (нужен публичный endpoint для `tauri-plugin-updater`).

## Фаза 0. Каркас проекта (фундамент)
**Цель:** пустое, но запускающееся Tauri-приложение.

- [ ] Инициализировать Tauri 2.x + Svelte + TS + Vite.
- [ ] Настроить Tailwind, ESLint/Prettier, структуру папок (`src/` UI, `src-tauri/` Rust).
- [ ] Базовое окно (пока обычное) + горячая перезагрузка.
- [ ] Git-репозиторий, `.gitignore`, README.

**Готово, когда:** `npm run tauri dev` открывает окно.

---

## Фаза 1. Overlay-окно (палитра)
**Цель:** всплывающее окно в стиле PowerToys.

- [ ] Frameless, прозрачное, always-on-top, по центру, скрыто из таскбара.
- [ ] Показ по глобальному хоткею (`tauri-plugin-global-shortcut`).
- [ ] Скрытие по `Esc` и по потере фокуса.
- [ ] Приложение живёт в фоне/трее для мгновенного показа; иконка в трее + меню (Открыть/Настройки/Выход).
- [ ] UI-скелет: поле ввода (автофокус), строка контекста, ряд кнопок, область пресетов.

**Готово, когда:** хоткей мгновенно показывает/прячет красивую палитру.

---

## Фаза 2. Интеграция с контекстным меню Windows
**Цель:** вызов из Проводника с передачей путей.

- [ ] Приём путей из аргументов командной строки.
- [ ] `tauri-plugin-single-instance` + дебаунс-агрегатор (~500 мс) для множественного выбора.
- [ ] Запись пунктов реестра при установке/по кнопке: `*` (файлы), `Directory`, `Directory\Background`.
- [ ] Строка контекста в UI отражает подтянутые файлы/папку.
- [ ] Скрипт удаления пунктов реестра (деинсталляция).

**Готово, когда:** ПКМ по нескольким файлам → одна палитра со всем списком.

---

## Фаза 3. ffmpeg: управление + выполнение + пресеты
**Цель:** реальная конвертация без ИИ.

- [ ] Проверка/автозагрузка ffmpeg+ffprobe в `%APPDATA%\...\bin\` с проверкой суммы и прогрессом.
- [ ] Сбор метаданных через ffprobe.
- [ ] Executor: запуск ffmpeg массивом аргументов, парсинг `stderr` → прогресс-события в UI.
- [ ] Отмена, очередь для нескольких файлов, шаблон имени вывода, обработка перезаписи.
- [ ] Набор ручных пресетов (MP4, сжатие, извлечение аудио, GIF, изображения, аудио).
- [ ] Уведомление о результате + «Открыть папку».

**Готово, когда:** выбор пресета реально конвертирует файлы с прогресс-баром.

---

## Фаза 4. Генерация команд нейросетью (MVP-фича)
**Цель:** текст на естественном языке → команда ffmpeg.

- [ ] Абстракция `AiProvider` (единый интерфейс).
- [ ] Облачный провайдер (OpenAI/Anthropic-совместимый), ключ в Credential Manager.
- [ ] Промпт-шаблон: системная инструкция + метаданные + запрос; ответ строго в JSON.
- [ ] **Валидатор команды** (whitelist бинарника, разбор аргументов, запрет опасных конструкций).
- [ ] Экран подтверждения: команда + пояснение + ручная правка → запуск.
- [ ] Обработка ошибок ИИ (нет ключа, таймаут, невалидный ответ).

**Готово, когда:** «сожми до 720p mp4» → валидная команда → успешная конвертация.

> **Конец MVP.** Дальше — улучшения.

## Порядок и приоритеты
1. **Сначала MVP (0→4)** — работающий вертикальный срез: overlay → контекст → конвертация → ИИ.
2. Фазы 5–7 — по мере надобности.
3. Риски вперёд: множественный выбор в контекстном меню (фаза 2) и валидация команд ИИ (фаза 4) — проверить раньше, это самые «острые» места.

## Стартовые технические риски
| Риск | Митигация |
|------|-----------|
| Множественный выбор файлов в классическом меню | single-instance + дебаунс-агрегация (заложено в фазе 2) |
| Небезопасная команда от ИИ | строгий JSON-ответ + валидатор + подтверждение пользователем |
| Прозрачный always-on-top overlay на разных DPI/мониторах | тест на мульти-мониторе рано, в фазе 1 |
| Лицензия/сборка ffmpeg | использовать статичные сборки с корректной лицензией (GPL/LGPL), фиксировать версию |
| Хранение чужих API-ключей | ключ вводит пользователь, хранится в Credential Manager, не логируется |
