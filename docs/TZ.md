# ТЗ — ConvPalette (рабочее название)

Приложение-конвертер файлов для Windows на базе **ffmpeg** с генерацией команд
через нейросеть. Интерфейс — всплывающая палитра команд поверх всех окон (стиль
PowerToys Run), вызывается из контекстного меню Проводника и подтягивает в контекст
выбранные файлы или папку.

---

## 1. Назначение и цель

Дать пользователю быстрый способ конвертировать/обрабатывать медиафайлы, не открывая
тяжёлых редакторов и не помня синтаксис ffmpeg:

1. Пользователь выделяет файл(ы) или папку в Проводнике → вызывает пункт контекстного
   меню → появляется палитра с уже подтянутым контекстом.
2. **Основной путь:** палитра сразу показывает **умные рекомендации** — подходящие
   целевые форматы/операции на основе типа выбранных файлов (напр. для `.mov` →
   «В MP4», «Извлечь аудио», «В GIF»). Пользователь кликает подходящую карточку.
3. **Запасной путь:** если рекомендации не подходят, пользователь пишет запрос на
   естественном языке («сожми до 720p и убери звук»), и нейросеть генерирует команду ffmpeg.
4. Команда показывается для подтверждения/правки → выполняется с прогресс-баром.

## 2. Стек (утверждён)

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| Каркас приложения | **Tauri 2.x** | Лёгкий (~5–10 МБ), нативный WebView, хорошая интеграция с ОС, малый расход памяти. |
| Бэкенд / логика | **Rust** | Запуск процессов, работа с ФС, реестром, глобальные хоткеи, безопасность. |
| Фронтенд (UI) | **Svelte + TypeScript + Vite** *(рекоменд.)* | Минимальный рантайм, идеален для лёгкого оверлея. Альтернатива — React + TS. |
| Стили | **Tailwind CSS** | Быстрая стилизация, тёмная/светлая тема. |
| ИИ | **Гибрид**: облачный API (OpenAI/Anthropic-совместимый) + локальный **Ollama** | Переключается в настройках. Дефолт — облако, есть офлайн-режим. |
| Медиа-движок | **ffmpeg + ffprobe** | Автозагрузка бинарников при первом запуске. |
| Хранение секретов | **Windows Credential Manager** (крейт `keyring`) | API-ключи не лежат в открытом виде. |
| Хранение настроек | JSON в `%APPDATA%\ConvPalette\` | Через `tauri-plugin-store`. |

### Ключевые плагины Tauri
- `tauri-plugin-single-instance` — агрегация нескольких вызовов из контекстного меню.
- `tauri-plugin-global-shortcut` — глобальный хоткей вызова палитры.
- `tauri-plugin-store` — настройки.
- `tauri-plugin-shell` / нативный `std::process` — запуск ffmpeg (с валидацией, **без** `shell=true`).

## 3. Функциональные требования

### 3.1 Всплывающая палитра (overlay)
- Окно: **frameless, прозрачный фон, always-on-top, по центру экрана, без иконки в таскбаре**.
- Появление: по глобальному хоткею (по умолчанию, напр., `Ctrl+Alt+Space`) **и** при вызове из контекстного меню.
- Скрытие: по `Esc`, при потере фокуса (клик вне окна), после запуска задачи.
- Содержимое:
  - **Поле ввода** запроса на естественном языке (в фокусе сразу при открытии).
  - **Строка контекста**: показывает, что подтянуто (напр. «3 файла: video1.mp4, …» или «Папка: D:\Clips»).
  - **Кнопки/иконки**: Настройки (⚙), Выбор пресета, История, переключатель ИИ облако/локально, кнопка «Выполнить».
  - **Быстрые пресеты** (см. 3.4) — как список/чипы.
- Реакция на ввод: показывает сгенерированную команду для подтверждения перед запуском.

### 3.2 Интеграция с контекстным меню Windows
- Пункты меню для трёх целей:
  - **на файле(ах)** (verb для `*` — все файлы, либо только медиатипы);
  - **на папке** (`Directory`);
  - **на фоне папки** (`Directory\Background` — текущая открытая папка).
- При вызове передаёт путь(и) в приложение.
- **Множественный выбор файлов**: классическое меню запускает по одному процессу на файл.
  Решение — `single-instance`: первый экземпляр становится хостом, последующие вызовы
  в окне ~500 мс агрегируются в один список путей → одна палитра со всеми файлами.
- MVP — классическое меню (в Win11 доступно через «Показать доп. параметры»).
  Полноценное меню Win11 (IExplorerCommand + sparse MSIX) — в бэклоге (см. PLAN, фаза 5).

### 3.3 Умные рекомендации форматов (основной механизм)
- На основе типа/метаданных выбранных файлов палитра формирует список **подходящих
  целевых операций** и показывает их карточками/чипами — это первое, что видит пользователь.
- Логика подбора — правила по категориям (видео / аудио / изображение / анимация):
  - видео (`mp4/mov/mkv/avi/webm`) → «В MP4 (H.264)», «Сжать», «Извлечь аудио (MP3)», «В GIF», «В WebM»;
  - аудио (`wav/flac/m4a/ogg`) → «В MP3», «В WAV», «В FLAC», «Нормализовать громкость»;
  - изображения (`png/jpg/webp/heic/bmp`) → «В JPG», «В PNG», «В WebP», «Изменить размер»;
  - смешанный выбор → общие безопасные операции (сжать, привести к одному формату).
- Каждая рекомендация — это параметризованный пресет (см. 3.4), применяется в один клик.
- Приоритет и содержимое списка настраиваемы в конфиге.

### 3.4-ai Генерация команд нейросетью (запасной путь)
- Используется, когда готовые рекомендации не подходят и пользователь вводит запрос текстом.
- Сбор контекста: для каждого файла через **ffprobe** снимаются метаданные
  (контейнер, кодеки, разрешение, битрейт, длительность, аудиодорожки).
- Промпт = системная инструкция + метаданные файлов + текст пользователя.
- Ответ модели — **строго структурированный** (JSON: `{ command, explanation, output_files }`),
  а не сырой текст, чтобы легко валидировать.
- Показ пользователю: сгенерированная команда + краткое пояснение, с возможностью
  **отредактировать вручную** перед запуском.
- Поддержка облака и локального Ollama через единый интерфейс-абстракцию `AiProvider`.

### 3.4 Ручные пресеты (без ИИ)
Быстрые кнопки для частых задач:
- Видео → MP4 (H.264/AAC)
- Сжать видео (720p / 1080p, битрейт по выбору)
- Извлечь аудио → MP3 / WAV
- Видео → GIF
- Конвертировать изображение (PNG/JPG/WebP)
- Аудио → MP3 / FLAC / WAV
- Обрезать / изменить разрешение
> Пресеты параметризуемы (целевой формат, качество). Список расширяемый в конфиге.

### 3.5 Выполнение и прогресс
- Запуск ffmpeg как дочернего процесса, парсинг `stderr` (`time=`, `frame=`) для прогресс-бара.
- Управление: отмена задачи, очередь при нескольких файлах.
- Именование вывода: настраиваемый шаблон (по умолчанию `имя_converted.ext` рядом с исходником),
  выбор папки вывода, обработка перезаписи (спросить/переименовать/пропустить).
- Итог: уведомление об успехе/ошибке, кнопка «Открыть папку».

### 3.6 Настройки
- Провайдер ИИ: облако / локально; endpoint, модель.
- API-ключ (в Credential Manager).
- Папка вывода и шаблон имени по умолчанию.
- Глобальный хоткей.
- Управление ffmpeg (путь, статус, кнопка «Скачать/Обновить»).
- Тема (тёмная/светлая/системная), автозапуск с Windows.

### 3.7 Управление ffmpeg
- При первом запуске проверка наличия ffmpeg/ffprobe.
- Если нет — загрузка статичной сборки для Windows в `%APPDATA%\ConvPalette\bin\`,
  проверка контрольной суммы, распаковка.
- Прогресс загрузки в UI; повтор при обрыве.

## 4. Нефункциональные требования

- **Производительность**: холодный старт палитры < 300 мс (процесс висит в трее/фоне для мгновенного показа).
- **Память в покое**: цель < 100 МБ.
- **Размер установщика**: без ffmpeg — компактный; ffmpeg докачивается.
- **Оффлайн**: полная работа с локальной моделью и пресетами без интернета.
- **Кроссплатформенность**: цель — Windows 10/11 x64. Архитектура не завязана намертво на Windows, но ОС-интеграция (контекстное меню) — Windows-специфична.

---

## 5. Безопасность (критично)

- **Никогда не запускать команду через shell со строковой интерполяцией.** ffmpeg вызывается
  с массивом аргументов; бинарник — только доверенный (наш ffmpeg), не произвольный.
- **Валидация команды от ИИ**: разбирать аргументы, whitelisting исполняемого (`ffmpeg`/`ffprobe`),
  запрет опасных конструкций (пайпы, `-f` в устройства, перезапись системных путей).
- **Prompt injection через имена файлов**: имя файла — данные, а не инструкция. Метаданные
  экранируются; вредоносное имя не должно менять поведение генерации. Финальную команду
  всегда подтверждает пользователь.
- **Секреты**: API-ключи только в Windows Credential Manager, не в JSON, не в логах.
- **Подтверждение**: любая команда показывается до запуска; вывод рядом с исходником —
  без удаления оригинала по умолчанию.

## 7. Открытые вопросы / предположения

1. **«Так же можно выбрать…»** — принято как *ручной выбор пресета/формата*. Подтвердить.
2. Облачный ИИ по умолчанию — какой провайдер/модель? (OpenAI, Anthropic, OpenRouter?)
   Ключ вводит пользователь сам (см. правила безопасности — приложение не хранит чужие ключи).
3. Нужны ли **не-медиа** конвертации (документы, архивы) или только то, что умеет ffmpeg? (ТЗ — только ffmpeg.)
4. Целевые версии Windows — подтвердить только 10/11 x64.
5. Название и иконка приложения.
