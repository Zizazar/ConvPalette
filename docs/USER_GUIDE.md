# ConvPalette — руководство пользователя

ConvPalette — всплывающая палитра-конвертер файлов для Windows на базе ffmpeg.
Выберите файлы, вызовите палитру — и конвертируйте в один клик по готовым
рекомендациям или опишите задачу своими словами для нейросети.

## Установка

1. Запустите установщик `ConvPalette_x.x.x_x64-setup.exe`.
2. Установка идёт в профиль пользователя — **права администратора не нужны**.
3. После установки запустите ConvPalette: приложение живёт в трее (иконка у часов).

При первом запуске:
- если ffmpeg не найден в системе, палитра предложит **скачать его одной кнопкой**
  (сборка BtbN, ~80 МБ, кладётся в `%APPDATA%\ConvPalette\bin`);
- в настройках (⚙) включите **«Пункт в контекстном меню Проводника»** и при желании
  **«Автозапуск при входе в Windows»**.

> Если вы раньше пользовались dev-версией, зайдите в настройки установленного
> приложения и пере-включите тумблер контекстного меню — пункт привяжется к
> установленному exe.

## Как вызвать палитру

| Способ | Как |
|---|---|
| Глобальный хоткей | **Ctrl+Alt+Space** (меняется в настройках) |
| Контекстное меню | ПКМ по файлу/файлам/папке → «Конвертировать (ConvPalette)» * |
| Трей | клик по иконке ConvPalette |
| Перетаскивание | бросьте файлы прямо в открытую палитру |

\* В Windows 11 пункт находится под «Показать дополнительные параметры» (Shift+F10).

## Конвертация

1. **Рекомендации** — палитра сама определяет тип выбранных файлов (видео / аудио /
   изображения) и показывает подходящие пресеты: «в MP4», «сжать», «извлечь звук»,
   «в GIF», «в WebP» и т.д. Клик по пресету → экран подтверждения с командой → «Конвертировать».
2. **Запрос к ИИ** — для нестандартных задач напишите в поле ввода, например:
   *«сжать до 720p и убрать звук»* или *«вырезать первые 30 секунд»*. ИИ предложит
   команду, которую можно посмотреть и при необходимости поправить перед запуском.
   Если команда ИИ упадёт с ошибкой ffmpeg, приложение автоматически отправит
   текст ошибки обратно нейросети и перезапустит конвертацию с исправленным
   вариантом (до двух попыток исправления).
3. Во время конвертации отображается прогресс по каждому файлу; задачу можно отменить.
4. Результат кладётся рядом с исходником (или в папку вывода из настроек) с именем
   по шаблону, по умолчанию `имя_converted.расширение`. Существующие файлы не
   перезаписываются — к имени добавляется номер.

## Настройка ИИ

В настройках (⚙) выберите провайдера:

- **OpenRouter (облако)** — вставьте API-ключ с [openrouter.ai/keys](https://openrouter.ai/keys)
  и укажите модель. Ключ хранится в **Диспетчере учётных данных Windows**, а не в файлах.
- **Ollama (локально)** — укажите URL (по умолчанию `http://localhost:11434`) и модель.
  Работает полностью офлайн, ключ не нужен.

Безопасность: ИИ не выполняет команды сам — он возвращает только параметры ffmpeg,
приложение проверяет их на опасные конструкции, строит пути само и показывает
итоговую команду перед запуском.

## Настройки

- **Папка вывода** — пусто = рядом с исходным файлом.
- **Шаблон имени** — `{name}` заменяется на имя исходника (по умолчанию `{name}_converted`).
- **Глобальный хоткей** — кликните по полю и нажмите нужную комбинацию
  (модификатор + клавиша, например Ctrl+Shift+K); Esc отменяет ввод. Если
  комбинация занята другой программой, ConvPalette возьмёт запасную и предупредит.
- **Скрывать при потере фокуса** — по умолчанию выключено: иначе палитра
  исчезала бы, как только начинаешь тянуть файл из Проводника.
- **Тема** — тёмная / светлая / системная.
- **Язык** — русский / английский, переключается мгновенно.
- **История** (🕘) — последние 30 конвертаций; клик по записи повторяет запрос/пресет.

## Удаление

«Параметры → Приложения → ConvPalette → Удалить». Деинсталлятор сам убирает пункты
контекстного меню и автозапуск из реестра. Настройки, история и скачанный ffmpeg
остаются в `%APPDATA%\ConvPalette` — удалите папку вручную, если они не нужны.
API-ключ можно удалить в «Диспетчере учётных данных Windows» (запись `ConvPalette`).

## Частые вопросы

**Хоткей не срабатывает.** Комбинацию перехватила другая программа — выберите иную
в настройках, либо перезапустите ConvPalette (при занятой комбинации он сам возьмёт запасную).

**Нет пункта в контекстном меню.** Проверьте тумблер в настройках. В Windows 11
пункт под «Показать дополнительные параметры». Пункт показывается только для
медиафайлов (видео/аудио/изображения) и папок.

**ИИ отвечает ошибкой.** Проверьте API-ключ и баланс OpenRouter, либо что Ollama
запущена (`ollama serve`) и модель скачана (`ollama pull …`).

**Палитра не открывается.** Проверьте, что процесс запущен (иконка в трее).
Запущен может быть только один экземпляр — повторный запуск просто передаёт файлы
уже работающему.
