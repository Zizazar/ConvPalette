# ConvPalette

Всплывающая палитра-конвертер файлов для Windows на базе **ffmpeg**. Вызывается
глобальным хоткеем или из контекстного меню Проводника, показывает умные
рекомендации форматов для выбранных файлов, а сложные задачи можно описать
текстом для нейросети.

> Статус: в разработке. Реализованы Фазы 0–4, 6 и 7 (инсталлятор).
> Дорожная карта — в [docs/PLAN.md](docs/PLAN.md), требования — в [docs/TZ.md](docs/TZ.md),
> руководство пользователя — в [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## Возможности
- Всплывающая палитра поверх окон (хоткей / трей / контекстное меню / drag&drop файлов).
- Умные рекомендации форматов по типу выбранных файлов (в один клик).
- Запрос к ИИ на естественном языке (OpenRouter или локальный Ollama) для нестандартных задач.
- Выполнение ffmpeg с прогрессом и отменой; авто-загрузка ffmpeg при отсутствии.
- История запросов и конвертаций (повтор в один клик).
- Настройки: провайдер/модель ИИ, API-ключ (в Credential Manager), папка вывода,
  шаблон имени, глобальный хоткей, тема (тёмная/светлая/системная), язык (ru/en),
  автозапуск, тумблер контекстного меню Проводника.

## Стек
- **Tauri 2** (Rust) — каркас, окно-overlay, трей, глобальный хоткей, single-instance.
- **SvelteKit + TypeScript** (SPA) — интерфейс палитры.
- **ffmpeg / ffprobe** — конвертация (из PATH или авто-загрузка BtbN-сборки).
- **ИИ** — OpenRouter (облако) + Ollama (локально), переключаемо; ключ в Windows Credential Manager (`keyring`), HTTP через `ureq`.

## Установка (пользователю)
Соберите или скачайте установщик `ConvPalette_x.x.x_x64-setup.exe` и запустите:
установка идёт в профиль пользователя (HKCU), права администратора не нужны.
Деинсталлятор автоматически подчищает пункты контекстного меню и автозапуск
(`src-tauri/windows/hooks.nsh`). Подробности — в [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## Сборка релиза
```bash
npm run tauri build
```
Инсталлятор появится в `src-tauri/target/release/bundle/nsis/`.
NSIS-инсталлятор двуязычный (ru/en), per-user. Подпись кода не настроена
(нужен сертификат); авто-обновления появятся после публикации репозитория
(нужен endpoint для `tauri-plugin-updater`).

## Запуск (разработка)
```bash
npm install
npm run tauri dev
```
Палитра скрыта по умолчанию. Вызов:
- глобальный хоткей **Ctrl+Alt+Space**;
- клик по иконке в трее;
- запуск с путями в аргументах (эмуляция вызова из контекстного меню):
  `cta-conv.exe "C:\путь\видео.mp4"`.

## Контекстное меню Проводника
Включается тумблером в настройках приложения (⚙ → «Пункт в контекстном меню
Проводника»). Запись идёт в HKCU — без прав администратора, привязывается к
текущему exe. Альтернатива — PS-скрипты:
```powershell
# добавить (в HKCU, без прав администратора)
./scripts/install-context-menu.ps1
# удалить
./scripts/uninstall-context-menu.ps1
```
В Windows 11 пункт появляется под «Показать дополнительные параметры» (Shift+F10).

## Структура
```
src/                 UI (SvelteKit)
  routes/+page.svelte  палитра
src/lib/i18n.svelte.ts локализация ru/en
src-tauri/src/
  lib.rs             окно, трей, хоткей, single-instance, команды
  presets.rs         классификация файлов + каталог пресетов + сборка команд ffmpeg
  ffmpeg.rs          поиск/загрузка ffmpeg и выполнение с прогрессом и отменой
  ai.rs              провайдеры ИИ (OpenRouter/Ollama), промпт, разбор ответа
  settings.rs        настройки (JSON) + API-ключ (Credential Manager) + история
  integration.rs     реестр Windows: контекстное меню, автозапуск
src-tauri/windows/hooks.nsh  хуки NSIS: очистка реестра при деинсталляции
scripts/             регистрация контекстного меню Windows (запасной путь)
docs/                ТЗ, план, руководство пользователя
```

## ffmpeg
Используется ffmpeg из PATH; если его нет — приложение предложит скачать
сборку BtbN в `%APPDATA%\ConvPalette\bin` (кнопка в палитре).
